# 📘 AI Code Review Assistant

Интерфейс для проведения автоматического ревью кода с использованием AI ассистента.

---

## 🚀 Цель проекта

Проверить пользовательский сценарий:

- Пользователь открывает страницу ревью.
- Вставляет или загружает файл с кодом.
- Нажимает кнопку "Отправить".
- Получает рекомендации от AI по улучшению кода.

---

## 💡 Особенности

- ✅ Мгновенная отправка кода на ревью.
- ✅ Получение AI комментариев по строкам кода.
- ✅ Поддержка загрузки файлов `.ts`, `.js`, `.py`, `.json`, `.txt` и других.
- ✅ Кнопка очистки истории чата.
- ✅ Автопрокрутка к последнему сообщению.
- ✅ Локальное сохранение истории через `localStorage`.
- ✅ Подсветка синтаксиса кода через PrismJS.
- ✅ Полная поддержка контракта OpenAI API (мок-ответ).

---

## 📄 Контракт OpenAI

Ответ от AI возвращается в формате:

```json
{
  "choices": [
    {
      "message": {
        "content": "{"comments": [{"line": 5, "comment": "Добавьте типизацию."}]}"
      }
    }
  ]
}
```

---

## 🛠️ Установка и запуск

```bash
npm install
npm run dev
```

Открой [http://localhost:5173](http://localhost:5173) для просмотра проекта в браузере.
